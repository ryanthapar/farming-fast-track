# Testimonial screenshots

Original WhatsApp screenshots behind the "The Day It Happened" section on the
landing page. Each card's **View the original message** button opens the file
named below in a lightbox.

The filename is referenced in `index.html` via `data-full` on the card's
`.wa-view` button — if you rename a file, update that attribute to match.

## Before adding a screenshot

- **Crop out phone numbers and personal contact details** that aren't already
  public marketing material.
- **Resize to roughly 900px on the long edge.** The originals are far larger
  than the lightbox needs, and page weight matters for ad traffic.
- **Keep the sender's name visible** — it's what makes the screenshot read as
  real rather than staged.

A missing file won't break the page: the lightbox shows a short "not available"
note instead of a broken image.
